LIMITES ET BLOCAGES PRÉCIS
1. MT5 : fichiers du terminal Wine présents, package Python natif absent, Wine
   non disponible dans le PATH. Indicateur non compilé, aucun export courtier
   disponible. Il reste à compiler/activer le lecteur dans un terminal utilisable
   et comparer son BID/ASK horodaté avec le graphique. Aucun identifiant demandé.
2. Une observation prolongée incluant minuit Paris et un trade naturel complet
   n’a pas été réalisée. Le cycle complet est testé avec données déterministes.
3. Les commissions et financements du courtier ne sont pas fournis : null,
   résultat net inconnu. Les montants renseignés produisent une estimation ;
   le modèle linéaire de financement ne reproduit pas les triples swaps.
4. Les fermetures exceptionnelles ne sont pas synchronisées automatiquement.
   Une journée manquante est rejetée ; une position ambiguë reste à auditer.
5. Le tableau de bord livré est terminal. Streamlit et l’hébergement permanent
   mentionnés dans la conception Notion n’ont pas été installés.
